This repository contains the code used to analyze Visium Spatial Transcriptomics and single cell RNA sequencing of the porcine maternal-fetal interface and swine trophoblast organoids (sTO) respectively. sTO Bulk analsis contains scripts and data needed to generate heatmaps and sex determination plots. All analysis for Visium and sTO clustering, cellchat, GO-term, and probabalistic modeling is contained in the Swine_analysis.RMD. Scripts needed to run trajectory analysis are in the sTO slingshot.rmd. Data used in these scripts are from the manuscript "Defining Cellular Diversity at the Swine Maternal-Fetal Interface Using Spatial Transcriptomics and Organoids". This manuscript was originally posted to bioRxiv under the DOI: https://doi.org/10.1101/2024.10.21.619461
Data is avaliable via SRA Bioproject PRJNA1252046 and GEO via accession GSE296975.
